# Frontend — AI Insurance Agent

React + JavaScript + Vite, run with Bun.

## Structure
- `src/components/` — shared UI (common, layout)
- `src/features/` — feature-scoped modules (auth, wallet, chatbot, voice-agent, insurance-application)
- `src/pages/` — route-level views
- `src/api/` — REST client and endpoint definitions
- `src/routes/` — route configuration
